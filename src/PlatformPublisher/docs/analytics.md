# 跨平台数据统计

## 入口和口径

主窗口顶部“数据统计”提供总览、数据分析、平台数据、账号数据和收入数据五个视图。

- 视频号采集视频总数、关注者、昨日播放/点赞/评论/净增关注、上架剧集、挂载视频、剧集播放量、广告变现、挂载、加热和预估违规扣除。
- 快手个人版采集经营者平台 T-1 日数据，按账号和短剧保存播放、点赞、评论、收藏与广告收益。
- 本地成功、失败和草稿数来自发布任务及逐素材完成事件。
- 视频号与快手收入分别汇总，不生成无业务意义的跨平台总收入。
- 平台明确返回的零值参与统计；缺失、未生成或采集失败不按零计算。

## 存储

统计数据库位于 `%LocalAppData%\YunfanPlatformPublisher\analytics.db`。金额以“分”的整数保存，界面和 CSV 再格式化为元。

同一账号、日期或短剧的重复采集采用幂等更新。已有成功日记录不会被后续临时失败覆盖。

## 刷新与补采

进入统计页时读取缓存，每个自然日首次进入会尝试线上刷新。发布任务正在运行时拒绝视频号统计采集。视频号补采按账号、日期串行执行，单次最多 31 天；再次执行会跳过已有成功日期。

“停止”会取消当前采集。已保存的数据不回滚，之后再次补采即可续跑。

## 历史导入

“导入云帆历史”只读访问：

```text
%APPDATA%\Yunfan\accounts.json
%APPDATA%\Yunfan\data\yunfan.sqlite3
%APPDATA%\Yunfan\analytics\weixin-channels\*.json
```

账号优先按相同稳定 ID 匹配，其次按平台和唯一同名账号匹配。无法唯一映射的账号不会导入，并在结果中报告。源数据库和 JSON 文件不会修改。

## 验收

真实账号首次验收建议分别选择一个视频号和一个快手账号：

1. 登录平台并保持发布队列空闲。
2. 在数据统计页点击“刷新数据”。
3. 对照平台页面核验昨日播放和收入。
4. 视频号补采 2 个自然日，确认重复执行不会产生重复记录。
5. 导出 CSV，使用 Excel 打开确认中文和金额格式。
