# TikTokPublisher（TikTok 多账号上传）

从 `ChannelsPublisher` **复制并独立演进**的 TikTok 短剧中心发布模块，**不依赖 Python `tiktok_uploader_client`**。

## 目标

- 多账号 + 每账号独立 WebView2 会话（切换账号只改 `IsVisible`，不重启浏览器）
- 每个账号可独立选择任意工作目录，队列项目自身记录执行账号
- Playwright CDP / 内嵌 WebView2 驱动 TikTok 上传
- 红果下载、AI 改写、海报等由本仓库 `ShortDrama.Infrastructure`（C#）实现

## 结构

```
src/TikTokPublisher/
  TikTokPublisher.Core/     领域层：账号、调度器、队列、工作目录
  TikTokPublisher.Ui/       Avalonia 视图 + WebView2 + Playwright 自动化
  TikTokPublisher.Desktop/  独立 WinExe 入口
```

## 运行

```powershell
cd D:\code\convertTools-main
dotnet run --project src\TikTokPublisher\TikTokPublisher.Desktop
```

## 账号登录

「发布配置」里的「登录账号」和「重新登录账号」优先使用国内站的邮箱密码接口。客户端用新会话查询剧集列表，通过后才保存到该账号的授权文件。验证码、限流或接口失败时会打开配置的内置或外部浏览器。国际站继续使用浏览器登录。

## 上传短剧的数据链路

「任务队列 → 上传短剧」弹窗显示当前账号、已保存的剧集类型和搜索链路。海外剧使用系统设置中的「海外剧数据链路」，本土剧使用「本土剧数据链路」。导入项目记录当时的账号和来源，切换左侧账号后，任务仍由原账号执行。

下载按任务账号的剧集类型读取当前系统设置。同类型更换数据链路后，程序用原剧名和实际总集数匹配新链路，只在唯一匹配时继续。账号缺失、剧集类型变化或无法唯一匹配时，队列会提示原因。实际下载链路见运行日志。

下载步骤核对原简介、原海报和本次要求的全部分集。缺失资料时按当前片源补取，仍有缺项则标记下载失败，保留已有素材供重试。下载验收通过后，队列才继续视频去重和后续步骤。

重试下载时会先核对本地分集。片源一致且分集齐全时，只补取缺少的原简介或原海报。强制重跑时会重新下载分集。

## 海报模式

在「TikTok 上传 → 发布配置」中选择「海报模式」，再保存账号配置。「AI 直接生成」由模型写入剧名，按图片预设的比例出图。「去字后固定字体写入」保留源图尺寸，由程序在无字底图上写入剧名。原先选择「参考原图生成新封面」的账号会使用「AI 直接生成」，保存账号配置时会记录该模式。

「AI 图片 API Key」下方的「图片提示词」按账号和海报模式分别编辑，保存账号配置后生效。留空或点击「恢复默认」使用当前模式的默认文本。「发送预览」可用示例剧名查看完整的提示词。直接生成会在原文后附上当前任务的剧名，图片尺寸取自图片预设。去字模式按原文生成底图，出图后由程序写入剧名。启用标题校验时，结果见运行日志。

临时接口或图片响应失败时，使用同一原图和提示词重试一次。模型审核拒绝时直接报告原因。生成失败或取消时会保留已有成品。

## 视频去重模板

在「TikTok → 视频去重」选择、新建、复制或编辑共享模板。保存模板后，可以将它设为当前账号的默认模板。旧账号的去重参数会保存为初始模板，能读取的旧命名模板也会加入模板库。删除被引用的模板时，需要先选择替代模板。

任务队列按各项目所属账号的默认模板执行视频去重，并在每次执行开始时固定参数。视频处理并发在系统设置统一管理。

## AI 改写简介

中英文短剧共用账号「发布信息提示词」，内置默认已包含简介轻改写规则。开启「AI 改写简介」后，队列把原简介与项目参数作为输入发送。模型请求或结果格式失败时，使用同一提示词和原始输入重试一次。队列会在保存前检查账号内剧名占用，冲突时显示原因并保留已有短剧信息。

安装或升级到此版本后，TikTok 客户端在授权通过后首次启动时，将本机全局及已有 TikTok 账号的发布信息提示词统一重置为新版默认值。此迁移在本机只执行一次，之后以用户保存的提示词为准。在「发布配置」点击「恢复默认」，再保存账号配置，可手动切回新版默认值。

项目的 `短剧信息.txt` 会把「原简介」写在「简介」上方，发布时读取「简介」。已有项目可在任务队列勾选后点击「补齐原简介」，从本地原素材、导入资料或同项目的改写历史补入。找不到可靠来源时，队列会提示缺失。

## 微信视频号上传

在主窗口左栏打开「视频号上传」。选择已有平台账号，或添加账号后在「账号配置」中扫码。旧版视频号账号和会话目录随平台数据继续使用。视频号与快手共用平台账号库，各自保存队列和步骤设置。独立云帆或视频号客户端占用工作区时会提示先退出。

- 进入视频号默认打开左起第一个「任务队列」。「素材发布」页和素材剪辑的发送入口暂时隐藏。此前保存的素材任务仍保留在本地。
- 左侧账号列表仅显示视频号账号。旧账号可通过「账号配置 → 关联已有账号」恢复关联。视频号工作目录单独保存。旧目录与快手目录相同时，请先核对并明确选择视频号要使用的目录。
- 保存草稿和正式发表分别记录结果。重启后可从原队列续跑。收到「待确认」时，先在该账号的视频号后台核对作品或草稿，再选中该素材并点击「核对待确认素材」。
- 「剧集上架」默认走浏览器。选择「接口」后，默认只上传材料和分集，保存回执，显示为「已上传、未提审」。勾选「上传并提审」后，核对账号、剧名和总集数再确认。接口提审要求从第 1 集连续到总集数，剧目简介最多 100 字。
- 「发布配置」只管理剧集上传表单。可为每个视频号账号新增多套方案并设为默认。字段留空时沿用项目配置，填写后使用方案值。「项目表单」读取项目剧集 JSON，显示字段来源、缺项与分集清单。项目 JSON 缺失时，先在任务队列执行「素材校验」，也可手动选择现有配置文件。
- 「保存到此项目」保存当前方案和本剧覆盖值，供「剧集上架」与「任务队列」共同使用。试看秒数大于 0 时按累计分集时长换算免费集数，上限 10 集，且不得超过总集数。AI 自动分类与文案生成使用系统设置里的文字模型。真人剧演员资料可通过接口方式填写。浏览器方式沿用项目的演员表单动作。
- 接口方式复用所选账号的登录快照。缺少登录态时，在「账号配置」重新扫码并打开视频号后台。项目内的 `.weixin-series-project-id` 用于在项目移位或归档后关联回执。
- 中断后再次执行可复用原素材回执。平台判定已有素材不可用时，可勾选「重新上传素材」。提审结果待确认时，请到视频号后台核对，再用「核对提审结果」登记。切换浏览器方式同样会检查接口提审记录。
- 「任务队列」按左侧所选账号显示剧集项目，并读取原云帆视频号剧集队列。可按剧名入队、扫描目录或导入本地项目。勾选项目和所需步骤后点击「执行勾选步骤」准备素材，点击「上传勾选剧集」并确认后按项目配置上传。勾选「仅待上传」可查看已通过素材校验并等待上传的项目。
- 「运行日志」可查看素材发布和任务队列的进度。素材队列保存在 `%LocalAppData%\YunfanPlatformPublisher\weixin\material-queue.json`，剧集队列保存在同一平台数据目录的 `app.db` 中。

## 素材剪辑

导入视频、拖入剧集目录，或通过「复制当前任务」为同一批素材配置不同版本。在「出片设置」为任务选择模式、条数、时长和输出目录。勾选其他任务后可批量应用当前剪辑配置，各任务保留自己的输出目录。开始队列时记录每条任务的参数，失败或停止后可以按本次参数重试。

在「成片」查看时长和来源集数，打开预览后可从开头、跨集切点或结尾回看。需要排查失败原因时打开「日志」。剪辑设置或输出目录变更后，该任务会回到待剪辑。默认剪辑设置中的模式和参数用于新导入的任务，服务配置在开始队列时读取。

### 剧情高光

在剪辑任务的「出片设置」选择「剧情高光」。剪辑时使用字幕或 ASR 的对白时间，以及 FFmpeg 检测的镜头切点，优先在对白间隙和换镜点剪切。配置 AI 文本接口后，模型可从已有候选中挑选并排列跨集剧情。AI 不可用或方案未通过校验时，使用本地选段和对白切点保护。

剧情高光仍按每条成片的时长范围和相似度配置出片。开启或关闭该选项会重新生成高光成片，同一配置下重新运行可复用已完成的视频。算法参考 [DramaClip v0.2.5](https://github.com/efarsoft/DramaClip/releases/tag/v0.2.5)。

当对白和镜头切点能定位重生等时空转场时，剧情高光会保留转场画面，并按剧情顺序衔接前后片段。结尾有问句时，会优先接上附近可确认的决定或答复，再复核时长和相似度。

剧情高光的「高级设置」可开启「本地 OCR 补充硬字幕」和「画面复评」。OCR 通过本机 Windows OCR 语言包读取硬字幕，补充缺失对白和选段线索。画面复评向所选视觉模型发送少量候选截帧，补选有画面依据的无对白或少对白镜头。可在「默认剪辑设置 → 服务配置」指定支持图片输入的 OpenAI 兼容接口，例如本地 Qwen3-VL。留空时复用 AI 文本服务。识别或复评失败时保留现有素材分析结果。
